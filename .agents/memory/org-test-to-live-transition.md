---
name: Organisation trial-to-live transition
description: Preferred treatment of an existing organisation used for a manager trial before students join.
---

When an existing organisation has been used for a trial and is about to be used by students, prefer renaming it and selectively removing test challenges rather than deleting or revoking it.

**Why:** The user chose to preserve the existing organisation and its memberships while clearing challenge history that would confuse incoming students. Ending challenges alone leaves them visible in history; revoking the organisation would disrupt access and start its retention/purge lifecycle.

**How to apply:** Use superadmin rename and individual challenge deletion with explicit confirmation; do not remove member accounts or personal activity records. Distinguish giving the user controls from actually editing published data.
